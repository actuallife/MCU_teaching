# 統計學（一）期中考複習網站

期中考範圍（第 1 – 5 章）的複習工具。單一 HTML 檔案，無後端、無追蹤，
開啟即用，可重複測驗並提供完整詳解。

- 課程：銘傳大學資訊管理學系　統計學（一）　115 學年度第 1 學期
- 教材：Camm 等著《Statistics for Business & Economics》15e（滄海圖書中譯本）
- 線上網址：<https://actuallife.github.io/MCU_teaching/statistics/midterm-review/>

## 範圍

| 章 | 單元 | 對應週次 |
| ---: | --- | --- |
| 1 | 統計概論與資料 | 第 1 週 |
| 2 | 敘述統計：表格與圖形 | 第 2 週 |
| 3 | 敘述統計：數值量數 | 第 3 週 |
| 4 | 機率基礎概念 | 第 4 週 |
| 5 | 離散機率分配 | 第 7 週 |

## 功能

| 模式 | 內容 |
| --- | --- |
| 模擬測驗 | 照期中考比重出卷：選擇題 10 題（50 分）＋ 計算與簡答 3 大題（50 分），題目橫跨五章 |
| 單章練習 | 挑一章集中練，每章抽 5 題選擇題 ＋ 1 大題計算，答完立刻看詳解 |
| 主題練習 | 挑一個細部主題（百分位數內插、貝氏定理、區間換算…），針對弱點 |
| 錯題複習 | 只出之前答錯的題目，答對兩次才從錯題本移除 |

- 每次進入都重新抽題、重新排列選項，同一份可以反覆練習
- 模擬卷保證橫跨五章（出題時依章節分散抽取）
- 數值題自動批改，每題標示容許誤差
- 簡答題顯示參考答案與評分要點清單，由作答者勾選自評，依比例給分
- 批改後顯示**依章節**與**依主題**兩層正確率，低於 60% 的會具體點名
- 每題標註章別與出處（例如「第 3 章　W3 P.21 百分位數：Lp 公式與內插」）
- 支援淺色／深色模式，手機寬度（約 400px）可正常使用

作答紀錄與錯題本存放在瀏覽器的 `localStorage`，**只留在使用者自己的裝置上**，
不會上傳到任何伺服器，因此教師端看不到班級作答統計。若需要收集數據，
請改用課堂問答系統或 Google 表單。

## 專案結構

```
MCU_teaching/
├── docs/                                   ← GitHub Pages 的根目錄
│   ├── index.html                          教材總覽頁
│   └── statistics/midterm-review/
│       └── index.html                      複習網站成品（單檔，159 KB）
└── src/statistics/midterm-review/          ← 本專案原始碼
    ├── README.md        這份說明
    ├── bank/            題庫，一章一個模組
    │   ├── common.py    mc()／calc() 與所有統計計算函式
    │   ├── ch1.py  ch2.py  ch3.py  ch4.py  ch5.py
    ├── build_bank.py    匯總各章 ＋ 121 項驗證 → questions.json
    ├── build.py         把題庫注入模板 → docs/.../index.html
    ├── template.html    頁面模板（CSS／HTML／JS，含題庫注入點）
    └── questions.json   題庫資料（由 build_bank.py 產生）
```

`build.py` 依自己所在位置自動推算輸出路徑（`src/<課程>/<單元>/` → `docs/<課程>/<單元>/`），
新增單元時整個資料夾複製一份改名即可，腳本不必修改。

## 建置

需要 Python 3.9 以上，無第三方套件。在本資料夾內執行：

```bash
python3 build_bank.py    # 匯總五章題庫，執行 121 項驗證 → questions.json
python3 build.py         # 注入模板 → docs/statistics/midterm-review/index.html
```

產出的 `index.html` 是完整的單一檔案，用瀏覽器直接開啟即可使用。

若要發布到 Claude Artifact（不含文件外殼的版本）：

```bash
python3 build.py --artifact
```

## 修改題目

**一章改一個檔案。** 例如要加一題機率的題目，只動 `bank/ch4.py`：

```python
mc("D19", T3, S_CON, True,
   "題目敘述……",
   ["選項 A", "選項 B", "選項 C", "選項 D"],
   1,                                    # 正解的索引（0 起算）
   "詳解內容，可以用 <b> 等 HTML 標籤。")

calc("DC6", T5, S_BAY, True,
     "題幹敘述……",
     parts=[
         {"label": "(1)", "type": "num", "unit": "",
          "q": "小題問題……", "ans": 0.3627, "tol": 0.002,
          "sol": "解題步驟……"},
         {"label": "(2)", "type": "text",
          "q": "簡答小題……",
          "ref": "參考答案……",
          "rubric": ["評分要點一", "評分要點二"]},
     ])
```

參數依序為：題號 ID、主題常數、出處、是否為講義相似範例。
**題號 ID 的前綴各章不同**（A/B/C/D/M 為選擇題，AC/BC/CC/DC/E 為計算題），
新增時沿用該章既有的前綴即可，`build_bank.py` 會檢查是否重複。

**答案請用運算式寫，不要手敲數字。** 各章模組上半部已經把情境的資料與統計量都算好
（例如 `SAL_MEAN`、`A_Q1`、`PF_A`、`SEC_MU`），詳解字串直接引用這些變數，
改了原始資料答案就會跟著變，不會對不上。`common.py` 提供了
`mean`、`median`、`lp`、`svar`、`ssd`、`cv`、`zscore`、`five_num`、`fences`、
`outliers`、`scov`、`corr`、`wmean`、`binom`、`pois`、`dist_stats` 等函式。

改完執行 `python3 build_bank.py`，它會跑 121 項檢查，包括：

- 題號不重複、每題四個相異選項、正解索引合法
- 每個數值小題都有容許誤差與解題步驟，且容許誤差不超過答案的 20%
- 每個簡答小題都有參考答案與至少兩項評分要點
- 每章題數足夠出卷（選擇 ≥ 8、計算 ≥ 2）
- 講義相似範例佔比是否仍達 70%
- 所有表格的欄數與表頭一致

任何一項不通過就不會輸出 `questions.json`，避免把錯誤的答案發布出去。
（開發過程中這組檢查抓到過三次：選項數值重複、第 3 章的中位數剛好等於眾數、
以及兩個投資方案的期望值原本沒有設計成相等 —— 那樣就失去「逼學生看 σ」的教學意義。）

若要檢查題號是否與既有的課堂問答系統題庫衝突：

```bash
python3 build_bank.py --check 舊題庫.csv
```
