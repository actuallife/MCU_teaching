# 離散機率分配複習網站

統計學（一）第 5 章「離散機率分配」的期中考複習工具。單一 HTML 檔案，無後端、無追蹤，
開啟即用，可重複測驗並提供完整詳解。

- 課程：銘傳大學資訊管理學系　統計學（一）
- 教材：Camm 等著《Statistics for Business & Economics》15e（滄海圖書中譯本）第 5 章
- 題目出處：第 7 週課堂簡報《離散機率分配》
- 線上網址：<https://actuallife.github.io/MCU_teaching/statistics/ch5-discrete-distributions/>

## 功能

| 模式 | 內容 |
| --- | --- |
| 模擬測驗 | 選擇題 10 題（50 分）＋ 計算與簡答 3 大題（50 分），一次送出一次批改 |
| 主題練習 | 五大主題各抽 6 題，答完一題立刻顯示詳解 |
| 錯題複習 | 只出之前答錯的題目，答對兩次才從錯題本移除 |

- 每次進入都重新抽題、重新排列選項，同一份可以反覆練習
- 計分比重對應期中考：選擇題 50%、計算與簡答 50%
- 數值題自動批改，每題標示容許誤差
- 簡答題顯示參考答案與評分要點清單，由作答者勾選自評，依比例給分
- 批改後顯示五大主題正確率，低於 60% 的主題會具體建議回去看哪幾頁投影片
- 每題標註出處投影片頁碼（例如「P.33 區間換算：本章最常見的失分點」）
- 支援淺色／深色模式，手機寬度（約 400px）可正常使用

作答紀錄與錯題本存放在瀏覽器的 `localStorage`，**只留在使用者自己的裝置上**，
不會上傳到任何伺服器，因此教師端看不到班級作答統計。若需要收集數據，
請改用課堂問答系統或 Google 表單。

## 題庫組成

共 39 題（選擇題 28 題、計算與簡答 11 大題，合計 48 小題）。
其中 **32 題（82%）為課堂講義範例的相似題** —— 換情境、換數字，但解法結構與講義完全相同：

| 講義範例 | 本站改編 |
| --- | --- |
| DiCarlo Motors 每日銷售量 | 手機行每日銷售量 |
| 電商 App 瀏覽商品頁數（練習 2／3） | 影音 App 單次觀看影片數 |
| 馬丁服飾店 n = 3、p = 0.30 | 門市成交 n = 4、p = 0.25 |
| 資安人工複核 n = 6、p = 0.20（練習 4） | n = 8、p = 0.15 |
| 客服專線 30 分鐘 6 通（練習 5） | 20 分鐘 5 通，問 8 分鐘 |
| 收費站 15 分鐘 10 輛車 | 機房門禁 30 分鐘 12 人次 |
| API 容量 μ = 3、上限 6 | μ = 4、上限 7 |
| 外包方案 A／B（期望值相同、σ 不同） | 兩案 E(X) 同為 50 萬，σ 相差 4 倍 |

其餘 18% 為延伸題：期望值的線性性質 E(aX+b)、變異數捷徑公式、
不放回抽樣為何不是二項分配、二項變異數在 p = 0.5 時最大，
以及三題觀念推導簡答（用指示變數推導 E(X) = np、為什麼變異數相加才需要獨立、
卜瓦松 E(X) = Var(X) = μ 在實務上的用途）。

| 隨機變數與機率分配 | 6 | 1 |
| 期望值與變異數 | 7 | 4 |

## 專案結構

本專案放在 `MCU_teaching` 教學 repository 底下，原始碼與成品分開擺：

```
MCU_teaching/
├── docs/                                          ← GitHub Pages 的根目錄
│   ├── index.html                                 教材總覽頁
│   └── statistics/ch5-discrete-distributions/
│       └── index.html                             複習網站成品（單檔，70 KB）
└── src/statistics/ch5-discrete-distributions/     ← 本專案原始碼
    ├── README.md        這份說明
    ├── bank.py          題庫定義與驗證 → questions.json
    ├── template.html    頁面模板（CSS／HTML／JS，含題庫注入點）
    ├── build.py         把題庫注入模板，產生成品
    └── questions.json   題庫資料（由 bank.py 產生）
```

`build.py` 會依自己所在的位置自動推算輸出路徑
（`src/<課程>/<單元>/` → `docs/<課程>/<單元>/`），
所以之後要新增章節，把整個資料夾複製一份改名即可，腳本不必修改。

## 建置

需要 Python 3.9 以上，無第三方套件。在本資料夾內執行：

```bash
python3 bank.py      # 產生 questions.json，並執行 24 項一致性驗證
python3 build.py     # 產生 docs/statistics/ch5-discrete-distributions/index.html
```

產出的 `index.html` 是完整的單一檔案，用瀏覽器直接開啟即可使用，
不需要起本地伺服器。

若要發布到 Claude Artifact，改用：

```bash
python3 build.py --artifact
```

兩者差別只在文件外殼：Claude Artifact 發布時會自行包上
`<!doctype>`／`<head>`／`<body>` 與最小重置樣式，所以 `--artifact` 版本不含這些，
以免重複。放到 GitHub Pages 或本機開啟請用預設版本。

## 修改題目

所有題目都定義在 `bank.py`，用兩個輔助函式新增：

```python
mc("M29", T3, "P.26 二項機率公式", True,
   "題目敘述……",
   ["選項 A", "選項 B", "選項 C", "選項 D"],
   1,                                    # 正解的索引（0 起算）
   "詳解內容，可以用 <b> 等 HTML 標籤。")

calc("C13", T4, "P.33 區間換算", True,
     "題幹敘述……",
     parts=[
         {"label": "(1)", "type": "num", "unit": "通",
          "q": "小題問題……", "ans": 2.0, "tol": 0.01,
          "sol": "解題步驟……"},
         {"label": "(2)", "type": "text",
          "q": "簡答小題……",
          "ref": "參考答案……",
          "rubric": ["評分要點一", "評分要點二"]},
     ])
```

參數依序為：題號 ID、主題、出處投影片、是否為講義相似範例。

**答案請用運算式寫，不要手敲數字。** 檔案上半部已經把所有情境的分配、
期望值與變異數都算好（例如 `SEC_MU`、`APP_VAR`、`GATE_P5`），
詳解字串直接引用這些變數即可，這樣改了資料之後答案會跟著變，不會對不上。

改完執行 `python3 bank.py`，它會跑 24 項檢查，包括：

- 題號不重複、每題四個相異選項、正解索引合法
- 每個數值小題都有容許誤差與解題步驟
- 每個簡答小題都有參考答案與至少兩項評分要點
- 講義相似範例佔比是否仍達 70%
- 用定義法與公式法交叉驗算每一個 E(X) 與 Var(X)
- 二項機率總和為 1、卜瓦松 E(X) = Var(X) = μ 是否成立

任何一項不通過就不會輸出 `questions.json`，避免把錯誤的答案發布出去。
（開發過程中這組檢查就抓到過一次：兩個投資方案的期望值原本沒有設計成相等，
那樣就失去「逼學生去看 σ」的教學意義。）
